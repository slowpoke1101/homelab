## gitea <img src="images/gitea.png" alt="png icon" width="24" height="24">

- self-hosted git server for configs, scripts, and a staging area for github pushes
- running on the Docker VM
- exposed through nginx proxy manager
- accessible from iOS and Fedora only, local or remote(tailscale)

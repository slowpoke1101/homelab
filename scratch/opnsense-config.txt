MAKE SURE TO APPLY BEFORE MOVING ON TO EACH STEP
created vlans interfaces - devices- vlan- add: tags 3, 4, 11, 22, 50, 99. parent device: ue0
go to assignments give it a description and add
click on each interface in the assignments window to enable. ipv4 configuration type: static, mtu 1500, add ipv4 .1 address assignment for each network, e.g. 10.1.88.1
go to services- dnsmasq- dhcp ranges you should see the vlan networks. edit to add interface name, set dhcp pool, subnet mask, lease time, etc.
Lastly go to firewall- rules. i added open connections for the moment just to test.

gs308e switch
the gui is pretty self explanatory. i chose the most advance vlan config option,
it lets you create a vlan based on a tag and assign them to ports either tagged untagged or excluded. then it also lets you change the pvid for each port.

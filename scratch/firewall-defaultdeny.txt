Im planning on switching my firewall rules from a default allow base to default deny. testing on sandbox50 i have an ubuntu server vm in there and with the current firewall rules, internet connection, and host isolation is good. i put at the top of the sandbox firewall ruleset a new block any to any rule and tested pings and digs from the vm and no connection, this is a good base. then above that rule i put allow from vm ip to netopia ip(running adguard listening on 53) port 53 and tested dig from the vm and it worked, but everything else didnt including outbound wan traffic. i changed the vm's nmcli dns to netopia and regular dig google.com worked but ping didnt, so dns is working but outbound internet connection is blocked. the fix was to create an alias named rfc1918 and include those networks in the alias. then create a rule above the default deny that says allow the network to rfc1918 alias and then click the destination/invert checkbox so that it allows everything BUT private address space and this enabled internet connections while blocking all my other vlans/networks, success.

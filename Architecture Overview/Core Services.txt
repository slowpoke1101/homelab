Core Services

DNS & DHCP: OPNsense provides dnsmasq DHCP and unboundDNS with domain overrides

Reverse Proxy Layer: Nginx Proxy Manager handles TLS termination with self-signed certifications, internal routing, and service exposure

Monitoring stack: Grafana, VictoriaMetrics, Node Exporter, and cAdvisor provide metrics, dashboards, and container visibility. UptimeKuma provides uptime alerts via discord

Backup & Storage: TrueNAS hosts SMB/NFS shares, snapshots and receives rsync backups from Docker VM. Raspi4 backup node receives rsync backups from TrueNAS

Application Services: immich, vaultwarden, memos, stirlingPDF, drawio, gitea, librespeed, iperf3
